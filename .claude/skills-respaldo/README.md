# Respaldo de skills

Copias de skills que viven sincronizadas desde la cuenta de claude.ai,
guardadas aquí para que un cambio hecho dentro de una sesión no se
pierda si el contenedor se recicla o si la sincronización sobrescribe
la copia local.

**Esto es un respaldo, no la fuente.** La versión que el sistema lee
es la sincronizada. Si un cambio de aquí tiene que quedarse, hay que
subirlo también a la skill en claude.ai.
