# Sistema de solicitud de eventos — Club Tigres

Paquete para que Claudia Elizondo arme su proyecto de Claude Cowork
alrededor del formulario de solicitud de eventos del estadio.

Preparado por Imara AI. Septiembre 2026.

## Qué hay aquí

| Archivo | Para qué |
|---|---|
| `01-prompt-entrevista.md` | El prompt que se pega como primer mensaje del proyecto. Claude entrevista a Claudia y escribe las instrucciones del proyecto. |
| `02-armar-el-proyecto.md` | Los pasos para crear el proyecto en Cowork y la carpeta de trabajo. |
| `03-plano-del-formulario.md` | Cómo debe quedar el formulario, campo por campo. Es el plano de construcción. |
| `04-reparto-de-tareas.md` | Qué hace Cowork, qué hace Power Automate, y por qué. |
| `pendientes.md` | Lo que falta definir. |

## Cómo se usa

1. Copia toda la carpeta `cowork-forms` a la computadora de Claudia,
   dentro de la carpeta que va a usar el proyecto.
2. Ella crea el proyecto en Cowork apuntando a esa carpeta
   (ver `02-armar-el-proyecto.md`).
3. Pega el prompt de `01-prompt-entrevista.md` como primer mensaje.
4. Claude lee el resto de los archivos como contexto y la entrevista.

## Orden recomendado

Primero el formulario en Microsoft Forms, porque sin respuestas
no hay nada que leer. Luego Cowork, que ya sirve desde el primer
día aunque los correos se manden a mano. Power Automate al final,
que es lo que necesita más configuración.
